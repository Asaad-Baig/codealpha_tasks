A classic, text-based interactive Hangman Game built using Python. The system randomly selects a secret word from a predefined list, and the player must guess it one letter at a time within a limited number of attempts.

✨ Key Features
Randomized Gameplay: Uses Python's built-in random module to select a new word each match.

Input Validation: Protects users from wasting turns on invalid characters, multi-letter inputs, or duplicate guesses.

Live Status Tracking: Displays clear visual feedback showing correctly guessed letters (p _ t h _ _), remaining incorrect attempts, and a history of used letters.

🛠️ Concepts Demonstrated
Control Flow: while loops and nested if-else condition statements.

Data Structures: Python lists for tracking user inputs and a predefined word bank.

String Manipulation: Dynamic display formatting using string methods.

🚀 How to Run the Game
Ensure you have Python installed on your system.


Open your terminal or command prompt and navigate to the game directory:
cd CodeAlpha_Hangman


Run the script:
python hangman.py
